# ORBIT

ORBIT is a responsive NASA image-discovery website developed for the University of the Witwatersrand Interactive Media 3B final exam.

The project is based on an approved UX/UI design process and technical specification. It provides a focused, image-only experience for discovering, exploring and saving NASA imagery.

## Project Status

Development in progress.

## Core Experience

ORBIT contains three main pages:

- Discover — introduces the experience and provides entry points into NASA imagery.
- Explore — allows users to search real NASA imagery using the NASA Image and Video Library API.
- Saved — stores selected images in the current browser/device using localStorage.

## Planned Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- NASA Image and Video Library API
- GSAP
- ScrollTrigger
- localStorage
- Git and GitHub
- GitHub Pages

## Development Priorities

- Responsive desktop and mobile layouts
- Real NASA API integration
- Loading, success, empty and error states
- Accessible keyboard interaction
- Reduced-motion support
- Three substantial GSAP interactions
- Reliable browser-based saved-image persistence
- Strong visual fidelity to the approved Figma design
